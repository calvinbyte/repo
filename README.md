Welcome to **XEC-Electrum**, your fast and reliable wallet for managing **eCash (XEC)**. Based on the proven Electrum platform, this wallet ensures speed, security, and full ownership of your crypto assets.

* * *

🌟 Features
-----------

* ⚡ Instant access — no full blockchain sync
    
* 🔐 Full control of your private keys
    
* 🖥️ Native apps for Windows, macOS, and Linux
    
* 🔌 Hardware wallet compatibility
    
* 🧩 Open-source, transparent, and verifiable

🛡️ Security Practices
----------------------

* Always verify PGP signatures and file hashes
    
* Never share your seed phrase — keep it offline
    
* Use a hardware wallet for enhanced safety
